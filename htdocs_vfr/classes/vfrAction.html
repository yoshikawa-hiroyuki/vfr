Description

vfrActionクラスは、描画領域に対する 仮想イベントの アクション(イベントハンドラ)の基底クラスである。

vfrActionクラスはインスタンスを作成する事はできない。
実際のアクションには、 vfrActionの派生クラス(デフォルトアクション群 またはプログラマが独自に作成する)を用いる。

Define Original Actions

 プログラマが独自にアクションを作成する事ができる。
アクションが満たしていなければならない条件は、以下のものである。
  • vfrActionクラスの派生クラスであること

  • 以下のパブリックメソッドを実装していること 
        void execute(class vfrEvent&)

アクションで記述しなければならないメソッドは execute() だけである。 ここでは、引数としてパスされた仮想イベントから イベント発生時の情報を取得し、これに対する動作を行うようコーディングする。

仮想イベントから取得できるイベント情報は、以下の通りである。

  • イベントが発生したスクリーン
  • イベント発生時のマウス位置
  • イベント発生時のマウス移動量
  • イベント発生時の入力キーコード

Register Original Actions

 作成したアクションは、以下の手順で、 特定の描画領域(vfrDrawArea)の 仮想イベントのイベントハンドラとして登録する。
  1. vfrDrawAreaのインスタンスを取得する
  2. vfrDrawAreaのイベントディスパッチャーを取得する
  3. イベントディスパッチャーからアクションを登録したい仮想イベントを取得する
  4. 取得した仮想イベントにアクションを登録する

Examples

 
// アクション MyAction の定義
//   マウスクリックされた位置を cerr に出力する
class MyAction : public vfrAction {
  public:
    void execute(vfrEvent& e) {
      vfrScreen* screen = e.getScreen();
      if ( ! screen ) return;
      Point2 mp;
      if ( ! e.getMPoint(mp) ) return;
      cerr << "Clicked (" << mp.x << ", " << mp.y << ")" << endl;
   }
} aMyAction;


  // アクションの登録
  //   MyActionクラスのインスタンス aMyAction を
  //   Click仮想イベントに登録する
  vfrDrawArea& da = .... ; // プラットフォームで異る
  vfrDispatch& dp = vfrDispatch::instance(da);
  vfrEvClick::instance(dp).regist(&aMyAction);

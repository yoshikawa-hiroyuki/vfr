Description

vfrCameraクラスは、グラフィックスシーンに対する視界を定義する、 カメラに対応したプリミティブの基底クラスである。

vfrCameraクラスは、インスタンスを作ることは出来ない。

Selection Test

 vfrCameraクラスは、OpenGLのセレクションテストへのインターフェースを持っている。
・clickSelect()
マウスクリックに対するセレクションテストのインターフェース。
ノードのピッキングを実装するものである。

・sweepSelect()
矩形領域に対するセレクションテストのインターフェース。
ラバーボックスを用いたセレクションを実装するものである。
どちらも、ウインドウ座標系(pixel単位で、左上隅が原点)でテスト領域の 中心座標と領域のサイズ(clickSelectでは サイズはVFR_SELECT_SUITE_SPOT×VFR_SELECT_SUITE_SPOTになる) を指定する。

結果は、メソッドの戻り値で返される。 これはunsigned int型の配列で、先頭の要素にテストに合格したノードの数が格納され、 続く要素にはテストに合格したノードのIDが、視点に近い順に格納される。
戻り値の内容は、次にセレクションテストを実行するか、 relaxSelect()を実行するまで有効である。

Feedback Test

 vfrCameraクラスは、OpenGLのフィードバックテストへのインターフェースを 持っている。
・clickFeedback()
マウスクリックに対するフィードバックテストのインターフェース。
頂点、面、辺などに対するピッキングを実装するものである。

・sweepFeedback()
矩形領域に対するフィードバックテストのインターフェース。
ラバーボックスを用いたエレメントフィードバックを実装するものである。
どちらも、ノードのIDでテスト対象となるノードを指定し、 ウインドウ座標系(pixel単位で、左上隅が原点)でテスト領域の 中心座標と領域のサイズ(clickFeedbackでは サイズはVFR_SELECT_SUITE_SPOT×VFR_SELECT_SUITE_SPOTになる) を指定する。

結果は、メソッドの戻り値で返される。 これはint型の配列で、先頭の要素にテストに合格したエレメントの数が格納され、 続く要素にはテストに合格したエレメントの番号(描画順に0からはじまる)が格納される。
戻り値の内容は、次にフィードバックテストを実行するか、 relaxFeedback()を実行するまで有効である。

Front Nodes

 vfrCameraクラスでは、setFrontNode()メソッドで 前景ノードを登録する事ができる。
前景ノードは、視界の幾何変換の影響を受けず、常に最前面に描画される。 また、前景ノードにはライトによる照光効果は 影響しない。

前景ノードにはシーン(vfrScene)を登録してはならない。 複数のノードを前景ノードに登録する場合は、 グループノード(vfrGroup)を用いる。
尚、シーンツリーのルートがvfrSceneではないため、 前景ノードにはデフォルトマテリアルは存在しない。 必要な場合は、alcMaterial()メソッドで 明示的に確保しなければならない。

前景ノードは独立した座標系で描画される。 描画範囲は、表示領域の天地(高さ)を基準にしており、下端が -1.0、上端が 1.0である。 左右の表示範囲は、表示領域のアスペクト比によって決まる。

Background Color

 vfrCameraクラスでは、表示領域の背景色をsetBgColor()メソッドで 指定する事ができる。
背景色では、Alpha成分は意味を持たない。

背景色は、フォグが有効な場合の混合色としても用いられる。

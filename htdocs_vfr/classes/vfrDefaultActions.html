Description

vfrDefaultActionsクラスは、描画領域に対して あらかじめ用意されているアクション(イベントハンドラ)群を 登録するためのユーティリティクラスである。

vfrDefaultActionsクラスはスタティックメソッドしか持っていない。

Default Actions

 SetDefaultAction()メソッドを コールする事で、デフォルトアクション群をいくつかの仮想イベントに一括して登録する事ができる。
SetDefaultAction()で登録されるアクションは、以下の通りである。
仮想イベント デフォルトアクション 動作
KeyIn vfrKeyInAction RETURNで幾何変換をリセット
ESCで終了(UNIX版のみ)
Click vfrClickSelectAction クリックセレクションテスト
DragStart vfrStartRBoxAction ラバーボックス描画開始
Drag vfrDrawRBoxAction ラバーボックス再描画
DragEnd vfrEndRBoxAction ラバーボックスセレクションテスト
SClick None なし
SDragStart None なし
SDrag vfrTransCameraAction
vfrTransObjAction 		カメラ平行移動
選択オブジェクト平行移動
SDragEnd None なし
CClick None なし
CDragStart None なし
CDrag vfrRotCameraAction
vfrRotObjAction 		カメラ回転
選択オブジェクト回転
CDragEnd None なし
SCClick None なし
SCDragStart None なし
SCDrag vfrScaleCameraAction
vfrScaleObjAction 		カメラ視野拡大縮小
選択オブジェクト拡大縮小
SCDragEnd None なし

デフォルトアクション群による動作は、マウス左ボタンに対して 以下のように設定されている。
  • (修飾キーを押さず)マウスクリックまたはマウスドラッグを行うと、 オブジェクトに対し セレクションテストを行い、 最も視点に近いオブジェクトを選択されたオブジェクト として、バウンディングボックスを表示する。
    セレクションテストに何も合格しない(背景をクリックなど)場合は、何も選択されていない状態とする。

  • SHIFTキーを押しながらマウスドラッグを行うと、 選択されたオブジェクトを マウスの移動量に応じて平行移動させる。
    何も選択されていない場合は、カメラ(視点)を平行移動させる。

  • CONTROLキーを押しながらマウスドラッグを行うと、 選択されたオブジェクトを マウスの移動量に応じて回転させる。
    何も選択されていない場合は、カメラ(視点)を回転させる。

  • SHIFTキーとCONTROLキーを両方押しながらマウスドラッグを行うと、 選択されたオブジェクトを マウスの移動量に応じて拡大／縮小させる。
    何も選択されていない場合は、カメラ(視点)を前後に移動させる。

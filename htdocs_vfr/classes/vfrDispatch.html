Description

vfrDispatchクラスは、描画領域(vfrDrawArea)に対する 仮想イベントディスパッチャーのクラスである。

イベントディスパッチャーは、 プログラマが仮想イベントハンドラーを設定する際の、仮想イベントのインスタンスを 取得するためのインターフェースである。

vfrDispatchインスタンスの取得には、常にinstance()メソッドを用いる。

Examples

vfrDispatchクラスを用いてvfrDrawAreaインスタンスの仮想イベントを取得するには、 以下のような手順をとる。 
  // vfrDrawAreaインスタンスの取得(プラットフォームで異る)
  vfrDrawArea& drawarea = .....;
  // vfrDispatchインスタンスの取得
  vfrDispatch& dispatcher = vfrDispatch::instance(drawarea);
  // KeyIn仮想イベントの取得
  vfrEvent& ki = vfrEvKeyIn::instance(dispatcher);
  ....

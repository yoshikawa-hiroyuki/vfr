vfrDrawAreaSDL* GetInstance()
vfrDrawAreaSDLクラスの(唯一の)インスタンスの取得を行う

Description

vfrDrawAreaSDLクラスは、グラフィックスの描画領域機能をSDLを用いて 実装したクラスである。

SDL環境ではアプリケーションから vfrDrawAreaSDLインスタンスを作成し、ウインドウ／描画領域として使用する。

Instance

vfrDrawAreaSDLクラスのインスタンスは、一つしか作成することはできない。 vfrDrawAreaSDLインスタンスの取得は、GetInstance() メソッドを用いて行う。

Description

vfrDrawRBoxActionクラスは、描画領域(vfrDrawArea)への ラバーボックスの再描画(ラバーボックスのサイズ変更)を行う デフォルトアクションのクラスである。

vfrDrawRBoxActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrDrawRBoxActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、イベント発生時のマウス位置を取得する
  • 以前に描いていたラバーボックスを消去する
  • マウス位置を終点に、ラバーボックス再描画する
これらの動作は、以下のコードで実装されている。 
void
vfrDrawRBoxAction::execute(vfrEvent& e) {
  Point2 cp;
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen )
    return;
  if ( ! e.getMPoint(cp) )
    return;
  if ( ! screen->isOnScreen(cp) )
    return;
  screen->clearRubberBox();
  screen->drawRubberBox(cp);
}

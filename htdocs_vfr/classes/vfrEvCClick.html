Description

vfrEvCClick, vfrEvRCClick, vfrEvMCClickの各クラスは、 描画領域に対するCClick、RCClickおよび MCClick仮想イベントを処理するイベントオブジェクトのクラスである。

描画領域に対してCONTROLキーを押しながらのマウスクリックがなされると、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvCClick(左クリック)、vfrEvRCClick(右クリック)または vfrEvMCClick(中クリック)インスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvCClick, vfrEvRCClick, vfrEvMCClickの各クラスは、 以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置

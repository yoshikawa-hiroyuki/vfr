Description

vfrEvCDragEnd, vfrEvRCDragEnd, vfrEvMCDragEndの各クラスは、 描画領域に対するCDragEnd、RCDragEndおよび MCDragEnd仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてCONTROLキーを押しながらのマウスドラッグが終了する (CONTROLキーまたはマウスボタンを離す)と、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvCDragEnd, vfrEvRCDragEnd, vfrEvMCDragEndインスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvCDragEnd, vfrEvRCDragEnd, vfrEvMCDragEndの各クラスは、 以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置
  • イベント発生時のマウス移動量

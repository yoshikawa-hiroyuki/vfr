Description

vfrEvClick, vfrEvRClick, vfrEvMClickの各クラスは、 描画領域に対するClick、RClickおよびMClick仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域に対してマウスクリックがなされると、vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvClick(左クリック)、vfrEvRClick(右クリック)または vfrEvMClick(中クリック)インスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvClick, vfrEvRClick, vfrEvMClickの各クラスは、 以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置

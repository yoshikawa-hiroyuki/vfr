Description

vfrEvDrag, vfrEvRDrag, vfrEvMDragの各クラスは、 描画領域に対するDrag、RDragおよびMDrag仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてマウスドラッグがなされると vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvDrag(左ドラッグ)、vfrEvRDrag(右ドラッグ)またはvfrEvMDrag(中ドラッグ)インスタンスに イベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvDragクラスは、以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置
  • イベント発生時のマウス移動量

Description

vfrEvDragEnd, vfrEvRDragEnd, vfrEvMDragEndの各クラスは、 描画領域に対するDragEnd、RDragEndおよびMDragEnd仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてマウスドラッグが終了する(マウスボタンを離す)と、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvDragEnd(左ドラッグ終了)、vfrEvRDragEnd(右ドラッグ終了)または vfrEvMDragEnd(中ドラッグ終了)インスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvDragEndクラスは、以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置
  • イベント発生時のマウス移動量

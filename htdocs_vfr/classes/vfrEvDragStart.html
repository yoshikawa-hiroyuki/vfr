Description

vfrEvDragStart, vfrEvRDragStart, vfrEvMDragStartの各クラスは、 描画領域に対するDragStart、RDragStartおよびMDragStart仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてマウスドラッグが開始されると、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvDragStart(左ドラッグ開始)、vfrEvRDragStart(右ドラッグ開始) またはvfrEvMDragStart(中ドラッグ開始)インスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvDragStart, vfrEvRDragStart, vfrEvMDragStartの各クラスは、 以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置

Description

vfrEvSCDragEnd, vfrEvRSCDragEnd, vfrEvMSCDragEndの各クラスは、 描画領域に対するSCDragEnd、 RSCDragEndおよびMSCDragEnd仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてSHIFTキーとCONTROLキーを同時に押しながらの マウスドラッグが終了する (SHIFTキー、CONTROLキーまたはマウスボタンのいずれかを離す)と、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvSCDragEnd、vfrEvRSCDragEndおよびvfrEvMSCDragEndインスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvSCDragEnd, vfrEvRSCDragEnd, vfrEvMSCDragEndのクラスは、以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置
  • イベント発生時のマウス移動量

Description

vfrEvSCDragStart, vfrEvRSCDragStart, vfrEvMSCDragStartの各クラスは、 描画領域に対するSCDragStart、 RSCDragStartおよびMSCDragStart仮想イベントを 処理するイベントオブジェクトのクラスである。

描画領域においてSHIFTキーとCONTROLキーを同時に押しながらの マウスドラッグが開始されると、 vfrDrawAreaクラスの 内部イベントハンドラはイベントディスパッチャーを介して 取得したvfrEvSCDragStart(左ドラッグ)、vfrEvRSCDragStart(右ドラッグ)、 vfrEvMSCDragStart(中ドラッグ)インスタンスにイベント情報を登録し、 各インスタンスに登録されているアクションを 実行する。

Event Information

 vfrEvSCDragStart, vfrEvRSCDragStart, vfrEvMSCDragStartの各クラスは、 以下のイベント情報をサポートする。
  • イベントが発生したスクリーン
  • イベント発生時のマウス位置

Description

vfrEventクラスは、描画領域に対する「仮想イベント」の 純粋基底クラスである。

Event Model

 vfrでは、描画領域(vfrDrawArea)に対するキーボード、マウスからの入力に関して、 vfr特有の「仮想イベント」を定義し、これに対するアクション(イベントハンドラ)を 登録する事により、イベントハンドリングを行う。

仮想イベントには以下のものがあり、それぞれ対応するクラス(vfrEventの派生クラス)が用意されている。

仮想イベント 対応するクラス イベントの意味
KeyIn vfrEvKeyIn キー入力(SHIFT, CONTROLキーを除く)
Click vfrEvClick マウス左クリック
DragStart vfrEvDragStart マウス左ドラッギング開始
Drag vfrEvDrag マウス左ドラッギング
DragEnd vfrEvDragEnd マウス左ドラッギング終了
SClick vfrEvSClick SHIFT+マウス左クリック
SDragStart vfrEvSDragStart SHIFT+マウス左ドラッギング開始
SDrag vfrEvSDrag SHIFT+マウス左ドラッギング

SCDragEnd vfrEvSCDragEnd SHIFT+CONTROL+マウス左ドラッギング終了

vfrDrawAreaの内部イベントハンドラでは、イベントディスパッチャーを介して 仮想イベントのインスタンスを取得し、ここにイベント情報を登録した上で、 仮想イベントに登録されているアクションをコールする。

static vfrImage* ReadImage(const char* fname, const Bool adjustFlg =TRUE)
wxWidgetsの機能を使用し、イメージ読み込みを行う(スタティックメソッド)
fname イメージファイルのパス
adjustFlg イメージサイズを 2n に合わせるかのフラグ (TRUE = 合わせる)

Description

vfrImageReaderWxクラスは、wxWidgets環境において wxWidgetsのイメージ処理機能を使用してイメージ読み込みを行う機能を実装するクラスである。

vfrImageReaderWxクラスは、スタティックメソッドである ReadImage()メソッドのみが実装されている。 このメソッドでは、第2引数にTRUEを指定すると、 OpenGLのテクスチャロードのために、イメージサイズが 2m × 2n になるようにイメージのクリップを行う。

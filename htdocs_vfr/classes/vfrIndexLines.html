Description

viTndexLinesクラスは、インデックス参照型の線分集合オブジェクトである。
与えられた頂点集合と、 頂点連結情報(インデックス)を参照し、 
	頂点[インデックス[i]]
を順に直線で連結する。

線分は、インデックスが要素終端の場合は連結しない。
また、ループモードがTRUEの場合は、 要素終端またはインデックスの終端に達した時に 線分を閉じ、閉多角形を描く。

RenderMode

vfrIndexLinesオブジェクトは、レンダリングモードがNONEかRT_POINT の場合を除き、getRenderMode()で返される レンダリングモードにRT_WIREを加える。

Feedback

フィードバックテストにおいて、vfrIndexLinesオブジェクトは フィードバックモード属性に応じ、 以下のような結果を返す。
FB_VERTEX
登録されている頂点順に0から付番された番号でフィードバックテストの結果を返す。

FB_EDGE
描画される順序で線分に0から付番された番号でフィードバックテストの結果を返す。
ループモードの設定によって、対応する線分の番号が変わる事がある。

FB_FACE
フィードバックテストは常に合格数 0 を返す。

Description

vfrIndexPolygonsクラスは、インデックス参照型の多角形集合を表示するオブジェクトクラスである。
与えられた頂点集合と、 頂点連結情報(インデックス)を参照し、 
	頂点[インデックス[i]]
の順に連結されるポリゴンを構成する。

ポリゴンは、インデックスが要素終端 またはインデックスの終端に達した時に線分を閉じ、閉多角形を描く。

vfrIndexPolygonsオブジェクトは、レンダリングモードがRT_POINTの場合、インデックスで参照されているいないにかかわらず 登録されている全ての頂点をポイントレンダリングする。

レンダリングモードがRT_WIREの場合、全てのポリゴンの辺を 閉じた連結線分として描画する。従って、辺が隣接するポリゴンが存在する場合、 その辺は2回レンダリングされる事になる。

レンダリングモードがRT_SMOOTH, RT_FLAT, RT_NOLIGHTのいづれかの場合、 タイリングモードがTRUEであれば レンダリング時にタイリングが実行される。
タイリングを行う事により、凹多角形、自己交差型多角形も正しくレンダリングされる。

Feedback

フィードバックテストにおいて、vfrIndexPolygonsオブジェクトは フィードバックモード属性に応じ、 以下のような結果を返す。
FB_VERTEX
登録されている頂点順に0から付番された番号でフィードバックテストの結果を返す。

FB_FACE
描画される順序でポリゴンに0から付番された番号でフィードバックテストの結果を返す。

FB_EDGE
フィードバックテストは常に合格数 0 を返す。

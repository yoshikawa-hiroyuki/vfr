Description

vfrKeyInActionクラスは、描画領域(vfrDrawArea)に対する キー入力処理を行う デフォルトアクションのクラスである。

vfrKeyInActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrKeyInActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、入力キーコードを取得する
  • 入力キーコードがRETURNならば、選択されたオブジェクトの幾何変換をリセットする
  • 入力キーコードがESCならば、プログラムを終了する
これらの動作は、以下のコードで実装されている。 
void
vfrKeyInAction::execute(vfrEvent& e) {
    if ( ! e.isKeyEvent() ) return;

    VFRkeyCode kc;
    if ( ! e.getKey(&kc) ) return;
    if ( kc == VFRKC_RETURN ) {
        vfrScreen* screen = (vfrScreen*)e.getScreen();
        if ( ! screen ) return;
        vfrObject* selectedObj = vfrDefaultActions::GetSelectedObj();
        if ( selectedObj ) {
            selectedObj->identity();
        } else {
            vfrCamera* camera = screen->getCamera();
            if ( ! camera ) return;
            camera->identity();
        }
        return;
    }
    if ( kc == VFRKC_ESCAPE ) exit(0);
}

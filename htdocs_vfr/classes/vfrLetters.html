Description

vfrLettersクラスは、文字(テキストグリフ)を表示するレンダリングオブジェクトの 基底クラスである。

テキストグリフはストロークフォントによって表現される。
ストロークフォントを実装したクラスのオブジェクトは、 通常のオブジェクト同様、視点からの距離、角度に応じたレンダリングが適用される。
テキストグリフはライトによる照光の影響は受けない。

vfrLettersクラスは、インスタンスを作ることは出来ない。

Fonts

フォントのサイズは、setFontScale()メソッドで設定する。
フォントのアライメントは、setFontAlign()メソッドで設定する。

Feedback

vfrLettersオブジェクトはフィードバックテストにおいて、 常に合格数 0 を返す。

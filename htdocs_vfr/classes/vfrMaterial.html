Description

vfrMaterialクラスは、グラフィックスプリミティブ(vfrNodeの派生クラス)の 表面属性を定義するためのクラスである。

vfrMaterialクラスで定義する属性は、以下のものである。

  • レンダリングモード
    RenderType型で シェーディング、ワイヤーフレーム、ポイントレンダリング、ノーライティングの いずれかを設定する。
    (デフォルト : RT_SMOOTH)
    これらのモードは、setRenderMode()において、 以下のように重複指定が可能である
    setRenderMode(RT_SMOOTH | RT_WIRE);

  • ラインタイプ
    レンダリングモードがRT_WIREの場合の線種を StippleType型で設定する。
    (デフォルト : ST_SOLID)

  • ライン幅
    レンダリングモードがRT_WIREの場合のラインの幅を設定する。 単位は画面上のPixelであり、拡大／縮小などの操作によって影響を受けることはない。
    (デフォルト : 1.0)

  • ポイントサイズ
    レンダリングモードがRT_POINTの場合の点の大きさを設定する。 単位は画面上のPixelであり、拡大／縮小などの操作によって影響を受けることはない。
    (デフォルト : 1.0)

  • ポリゴン表示面
    レンダリングモードがRT_SMOOTH, RT_FLAT, RT_NOLIGHTのいづれかの場合の 描画する面の設定を行うもので、間接的に面のカリング(Culling)の設定を行うものである。
    設定はPolyFaceType型で指定し、 PF_FRONTまたはPF_BACKの場合のみカリングが実行される。
    (デフォルト : PF_BOTH)

  • 反射係数
    レンダリングモードがRT_SMOOTH, RT_FLATの場合に、 ライティングオブジェクトで設定される光源の 光学的影響をどれだけ受けるかの属性を設定する。
    設定する項目は、以下の通りである。
    • 鏡面反射係数(デフォルト : (0.0, 0.0, 0.0, 1.0))
    • 環境光反射係数(デフォルト : (0.2, 0.2, 0.2, 1.0))
    • 鏡面反射指数(デフォルト : 5.0)
    • 放射光色(デフォルト : (0.0, 0.0, 0.0, 1.0))
    鏡面反射指数を除くいずれも、Red, Green, Blue, Alphaの各成分を [0.0〜1.0]の範囲で指定する。
    尚、拡散反射係数にはオブジェクトの色が用いられる。

  • ライン代替色
    ライン代替色は、レンダリングモードがRT_WIREの場合に オブジェクトが持つ色データを無視し、ラインの色として用いる属性であり、 ライン代替色参照モードがTRUEの時のみ有効になる。
    ライン代替色は、ポリゴン面とワイヤーフレームを合成して表示する時 (レンダリングモードが"RT_FLAT | RT_WIRE"の場合など)に、 ラインだけを別の色(不透明度(Alpha)を含む)で描画するために使用する。

  • ポイント代替色
    ポイント代替色は、レンダリングモードがRT_POINTの場合に オブジェクトが持つ色データを無視し、ポイントの色として用いる属性であり、 ポイント代替色参照モードがTRUEの時のみ有効になる。
    ポイント代替色は、ポリゴン面とポイント(頂点)を合成して表示する時 (レンダリングモードが"RT_FLAT | RT_POINT"の場合など)に、 ポイントだけを別の色(不透明度(Alpha)を含む)で描画するために使用する。

Material Stack

vfrMaterialクラスのインスタンスは、vfrNodeの メンバーとして登録され、シーンのレンダリング時にシーンツリーの構成に応じて スタックされ、そのトップのマテリアルがカレントマテリアルとして有効になる。

Fig.1のシーンツリーにおいては Scene, Object1, Branch1のみがマテリアルメンバーを持っている。 この場合、各オブジェクトをレンダリングする際のマテリアルスタックは 以下のようになる(右端がカレントマテリアル)。

Object0
Material0
Object1
Material0 : Material1
Object2
Material0 : Material2
Object3
Material0
Fig.1において、Material0のレンダリングモードが RT_WIRE(ワイヤーフレーム)で、Material1, Material2のレンダリングモードが RT_SMOOTH(スムースシェーディング)である場合、 Object0とObject3はワイヤーフレームで、Object1とObject2はスムースシェーディングで レンダリングされる。

各オブジェクトのマテリアルを明示的に設定したい場合は、 それぞれのオブジェクトに対し、alcMaterial()メソッドで vfrMaterialインスタンスを確保する必要がある。

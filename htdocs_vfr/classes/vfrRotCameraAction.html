Description

vfrRotCameraActionクラスは、 マウスドラッギングに対応したカメラ(視点位置)の回転を行う デフォルトアクションのクラスである。

vfrRotCameraActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrRotCameraActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、マウス移動量を取得する
  • 移動量に応じて、カメラを回転させる
これらの動作は、以下のコードで実装されている。 
void
vfrRotCameraAction::execute(vfrEvent& e) {
  Point2 mv;
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen ) return;
  if ( ! e.getMMove(mv) ) return;
  vfrCamera* camera = screen->getCamera();
  if ( ! camera ) return;
  camera->dragRot(mv.x, mv.y);
}

Description

vfrScaleCameraActionクラスは、 マウスドラッギングに対応したカメラ(視点位置)の視界の拡大／縮小を行う デフォルトアクションのクラスである。
視界の拡大／縮小操作は、視点位置を視線方向に前後に移動する事で実現される。

vfrScaleCameraActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrScaleCameraActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、マウス移動量を取得する
  • 移動量に応じて、カメラを視線方向に前後に移動させる
これらの動作は、以下のコードで実装されている。 
void
vfrScaleCameraAction::execute(vfrEvent& e) {
  Point2 mv;
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen ) return;
  if ( ! e.getMMove(mv) ) return;
  vfrCamera* camera = screen->getCamera();
  if ( ! camera ) return;
  camera->dragTransZ(mv.x, mv.y);
}

Description

vfrScaleNodeActionクラスは、 マウスドラッギングに対応して、選択されたノードの拡大縮小を行う デフォルトアクションのクラスである。

vfrScaleNodeActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrScaleNodeActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、マウス移動量を取得する
  • パスされた仮想イベントからイベント発生スクリーンを取得し、そのサイズを得る
  • 選択されたノードがある場合、 マウス移動量とスクリーンサイズの比に応じて、選択ノードを拡大縮小させる
これらの動作は、以下のコードで実装されている。 
void
vfrScaleNodeAction::execute(vfrEvent& e) {
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen ) return;
  vfrNode* selectedNode = vfrDefaultActions::GetSelectedNode();
  if ( ! selectedNode ) return;
  screen->scaleNode(selectedNode->getID(), e.getMPoint(), e.getMMove());
}

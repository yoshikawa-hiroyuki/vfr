Description

vfrStartRBoxActionクラスは、描画領域(vfrDrawArea)への ラバーボックス描画を開始する デフォルトアクションのクラスである。

vfrStartRBoxActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrStartRBoxActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、イベント発生時のマウス位置を取得する
  • マウス位置を始点に、ラバーボックスの描画を開始する
これらの動作は、以下のコードで実装されている。 
void
vfrStartRBoxAction::execute(vfrEvent& e) {
  Point2 cp;
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen )
    return;
  if ( ! e.getMPoint(cp) )
    return;
  screen->startRubberBox(cp);
}

Description

vfrTransCameraActionクラスは、 マウスドラッギングに対応したカメラ(視点位置)の平行移動を行う デフォルトアクションのクラスである。
この平行移動は、視線方向と垂直な平面内で適用される。

vfrTransCameraActionクラスのインスタンスはプログラム内で1つだけ存在し、 その取得にはinstance()メソッドを用いる。

Behavior

vfrTransCameraActionクラスは、execute()メソッドがコールされると、 以下の動作を行う。
  • パスされた仮想イベントから、マウス移動量を取得する
  • 移動量に応じて、カメラを平行移動させる
これらの動作は、以下のコードで実装されている。 
void
vfrTransCameraAction::execute(vfrEvent& e) {
  Point2 mv;
  vfrScreen* screen = (vfrScreen*)e.getScreen();
  if ( ! screen ) return;
  if ( ! e.getMMove(mv) ) return;
  vfrCamera* camera = screen->getCamera();
  if ( ! camera ) return;
  camera->dragTrans(mv.x, mv.y);
}
